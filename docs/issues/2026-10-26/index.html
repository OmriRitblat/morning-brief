Artificial intelligencePage 4

NVIDIA's ReplaySSM speeds up decoding in hybrid state-space and attention models

A new way to store SSM state cuts memory traffic and makes speculative decoding work at serving batch sizes.

NVIDIA's technical blog describes ReplaySSM, a technique for hybrid models that mix state-space (SSM) layers with a few attention layers, such as Nemotron 3. At serving batch sizes, SSM layers can bottleneck decoding because each step loads and stores the whole state while doing little arithmetic, so HBM bandwidth is the limit. Speculative decoding also helps little, since an SSM state has no cheap rollback, so engines like vLLM store a snapshot per draft token.

ReplaySSM keeps a checkpoint plus a small buffer of recent inputs (window of 16 in the tests). Most steps just append to the buffer and compute outputs from checkpoint plus buffer; the checkpoint is rewritten only when the buffer fills. Rolling back rejected draft tokens becomes a pointer move. On four hybrid models on H100 or B300 GPUs, NVIDIA reports 1.20x to 1.47x end-to-end decode-step speedups at batch 256, and 1.85x to 2.10x the throughput of vLLM's speculative decoding at batch 512 on 120B-class models. The post says it is integrated into TensorRT-LLM, vLLM, SGLang and FlashInfer.

Sources: NVIDIA Technical Blog

TensorRT 11.1 adds the Global Performance Tuner

A single antimatter particle in a cage opens door to 'revolutionary' physics

Physicists trapped and cooled one positron for months to measure its magnetic moment very precisely.

The positron is the antimatter twin of the electron. Nature's news team reports that physicists have held a single positron in a trap for months and cooled it, so they can measure its magnetic moment, a number describing how it behaves like a tiny magnet, with very high precision.

This summary is based on the article's feed description and headline only; the full text was behind a login. Precision measurements like this are one way to test whether matter and antimatter behave identically, which is why the article's headline speaks of 'revolutionary' physics.

  1. What they found: a single positron can be kept caged for months.
  2. How: the particle was trapped and cooled so it could be measured very precisely.
  3. Why it matters: a precise magnetic moment gives a sharp test of matter-antimatter symmetry.

Queue pairs and work requests: how an RDMA send is posted

Monday track: RDMA and NICs

What it is
A queue pair (QP) is a pair of work queues, a send queue and a receive queue, that live in memory shared between your process and the NIC. You describe each operation as a work queue entry (WQE) and the NIC executes it without the kernel.
How it works
The app fills a WQE (control segment with opcode, data segments with address, length and lkey), writes it into the next slot of the send queue ring, updates the doorbell record, and rings the doorbell by writing to a NIC register. The NIC DMA-reads the WQE, fetches the data using the memory region's keys, transmits, and later writes a completion entry (CQE) into the completion queue.
Why it matters for XLIO
XLIO builds its user-space TCP/UDP stack on these queues: it posts send WQEs and polls receive and completion queues from user space, so the data path has no system calls or interrupts.
Example
Think of a restaurant ticket rail: the cook (NIC) watches a rail of order slips (the ring). You clip a slip on the rail, then ring the bell (doorbell) so the cook knows to look.
Key numbers
mlx5 send WQE building block (WQEBB)64 bytes
Queue deptha power of two, so index wrapping is a bitmask
Doorbellone MMIO write per batch of WQEs, not per WQE
Common pitfall
Posting a WQE does not mean it was sent. The send is only done when its CQE arrives, and the buffer must stay untouched until then.
Self-test: Why does posting ten WQEs and ringing the doorbell once usually beat ringing it ten times?

The doorbell is an uncached write across PCIe, which is expensive compared with filling memory. Batching amortizes that cost over many WQEs, at the price of a little added latency for the first one.
